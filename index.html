Quick start

How to use the new lab

1

Add compounds to your inventory

Use the composer to create chemicals by formula, then search or filter them in the inventory list.

2

Open the playground modal

The main chemistry playground now opens in a dedicated modal. The compound deck scrolls above the beaker so you can drag or tap tubes into the queue.

3

Run the reaction

Pick an environment, optionally add a catalyst, and run the mix. The beaker scene and live effect inspector both update from the real API response.

4

Reuse products and track rewards

Products land on the bench for quick reuse, while the sidebar keeps awards, notifications, and rankings in view.
